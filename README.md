# إضافات كلود: مهارتين ببلاش، بدون تسجيل دخول

هدول المهارتين اللي حكيت عنهم بالبوست. بتركّبهم مرة وحدة، وبيضلّوا مع كلود على طول. ما بدهم حساب ولا مفتاح ولا أي اشتراك غير Claude.

— أسامة جمال AI

| المهارة | شو بتعمل |
|---|---|
| **Frontend Design** | المواقع والصفحات اللي بيعملها كلود بتطلع إلها شخصية، مش شكل «عملو AI» |
| **Skill Creator** | بتعمل مهارة خاصة إلك: بتشرح لكلود مرة وحدة، وهو بيحفظها للأبد |

## شو بتحتاج
1. **اشتراك Claude Pro**، وتطبيق **Claude** على الكمبيوتر (من claude.ai/download)
2. **Claude Code**: من التطبيق افتح تبويب **Code**

## التثبيت (مرة وحدة)

**أسهل طريقة:** افتح Claude Code، وابعتله هالجملة:
> ثبّتلي المهارات من https://github.com/osamajamalai/claude-addons

وهو بيعمل كل إشي لحاله.

**أو يدوي:**
1. فوق بهالصفحة اضغط الزر الأخضر **Code** ← **Download ZIP**
2. فك الضغط، وافتح مجلد `skills` اللي جوّاه
3. انسخ المجلدين (`frontend-design` و`skill-creator`) لمجلد المهارات:
   - **Windows:** `C:\Users\<اسمك>\.claude\skills\`
   - **Mac:** `~/.claude/skills/`
   (إذا مجلد `skills` مش موجود، اعمله)
4. سكّر Claude وافتحه من جديد

## الاستعمال
- **Frontend Design:** اطلب من كلود أي صفحة أو موقع عادي، متل «اعملي صفحة لمطعمي»، والمهارة بتشتغل لحالها.
- **Skill Creator:** قلّه «بدي أعمل مهارة» واشرحله شو بتعيد كل يوم، وهو بيعملها وبيركّبها.
